# herdr-mods

My mods for the [Herdr](https://herdr.dev) desktop app. Each folder is one entry on [herdr.dev/mods](https://herdr.dev/mods), with its own `RECIPE.md`, `preview.png` and `mods/`.

| Mod | What it does |
| --- | --- |
| [Universal auto tabs](universal-auto-tabs/) | Tabs name themselves after what runs in them: an agent's conversation title, else the program, else the folder. Spaces follow their active tab, and the agents list shows tab names. |
| [Desktop notifications](desktop-notifications/) | Herdr's "needs you" and "finished" alerts also go to the macOS Notification Center or a Linux notification daemon. Click one to jump to that agent. |

To add one, ask your Herdr agent: `Read ~/.config/herdr-app/AGENTS.md, then add this mod: https://github.com/benjaminsicard/herdr-mods/tree/main/<folder>`. Each folder's README also has steps for installing by hand.
